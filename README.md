# Text Encryption Experiments

A collection of Python experiments exploring text substitution and bitwise encoding techniques.

# Overview

This project explores two approaches to transforming text using Python:

- **Character substitution:** constructing a key from the characters in a message and replacing characters in pairs.
- **XOR-based encoding:** converting text into binary data and applying the bitwise exclusive OR (XOR) operation with a key.

The notebook also includes examples of encoding and decoding messages.
